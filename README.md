# Todo CLI                                                                                                                                                                
                                                                                                                                                                            
  A simple command-line todo app built with Kotlin.
                                                                                                                                                                            
  ## Installation                                                                                                                                                           
                                                                                                                                                                            
  brew tap BogdanMatran/todo 
  
  brew install todo

  ## Usage

  todo add "Buy milk"
  
  todo list
  
  todo done 1
  
  todo reset 1
  
  todo delete 1
  
  todo help

  ## Uninstall

  brew uninstall todo
  
  brew untap BogdanMatran/todo
